# Create Mechanical Chicken

Addon for create.
Generates milk with rotation and item ingredient.

## Features

- Mechanical Cow Kinectic block.
- Ponder
- Compat: JEI & JADE
- Configurable:
    - Processing time
    - Output amount
    - Output fluid
    - Stress impact
    - Fluid capacity
    - Required ingredient
    - Required ingredient amount
    - Sound volume
